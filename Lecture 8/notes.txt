why comopnent didMount is used for Api calling ?
and -> why exactly componentDidMount()?

Because it satisfies all constraints:
1️⃣ Runs after first render
UI renders immediately (better UX)
DOM exists
No blocking
2️⃣ Runs only once (on mount)

Perfect for:
Initial data fetching
Subscriptions
Timers
3️⃣ Safe place for side-effects

React explicitly designed it for:
API calls
Event listeners
Non-React code


Why not in constructor ?
Ans -> Constructor can run multiple times in future React versions
DOM is not ready
Side-effects in constructor break React’s async rendering model\
