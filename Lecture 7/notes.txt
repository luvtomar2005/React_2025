There are two types of routing are there -:
1. Client side routing ->
Browser loads / once
JS bundle downloads
When URL changes to /about:
NO server request
Router (JS) intercepts it
Component swaps in the browser
Page does NOT reload


2. Server side routing ->

Browser requests /about
Request goes to server
Server:
runs backend code
selects route
renders HTML
Server sends new HTML page
Browser reloads the page
