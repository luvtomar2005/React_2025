Why to use the usestate in search text?
What YOU expect:

searchText contains latest input

Button uses it

What ACTUALLY happens:

searchText is reset to ""

Value is lost

“Whenever something changes on the UI, we need state.”

Why?
Because React must:

Detect the change

Re-run the component

Update the UI

Normal variables cannot do this.

What Problem useState Solves (Exactly)

Without useState:

React does not know what changed

React does not re-render

UI stays stale

With useState:

React tracks the variable

React re-renders on update

UI updates automatically
